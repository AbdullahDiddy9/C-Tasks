Employee Highest Salary Finder
=================================

A program that uses a struct to store employee data and finds out
who has the highest salary among 3 employees.

How it works:
---------------
- Defines a struct "Emp" with name, age, and salary.
- Creates 3 Emp objects (e1, e2, e3) and sets their name and age.
- Asks the user to enter salary for each employee.
- Puts all 3 employees into an array "arr".
- Uses a pointer "ptr" pointing to the start of that array.
- Loops through the array comparing salaries to find the index of the
  employee with the highest salary.
- Prints the name of the employee with the highest salary.
