# C++ Practice Programs

A collection of simple C++ programs written while practicing core programming concepts like loops, recursion, and basic math operations.

## Files

| File | Description |
|------|-------------|
| `digit_count.cpp` | Counts the number of digits in a given number. |
| `digits_sum.cpp` | Calculates the sum of digits of a given number. |
| `evennumbers.cpp` | Prints even numbers within a given range. |
| `factorial.cpp` | Calculates the factorial of a given number. |
| `fibonacci.cpp` | Prints the Fibonacci series up to a given number of terms. |
| `numbers_print_.cpp` | Prints numbers from a starting point to an ending point using recursion. |
| `power.cpp` | Calculates the power of a number (base raised to an exponent). |
| `reverse.cpp` | Reverses the digits of a given number. |
| `sum.cpp` | Calculates the sum of two or more numbers. |

## How to Run

1. Compile any file using a C++ compiler:
   ```bash
   g++ filename.cpp -o filename
   ```
2. Run the compiled program:
   ```bash
   ./filename
   ```

## Note

These programs were written for practice purposes and are kept simple and beginner-friendly.
