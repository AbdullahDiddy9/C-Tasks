C++ PRACTICE PROGRAMS
======================

A collection of simple C++ programs written while practicing core
programming concepts like recursion, loops, and basic math operations.


FILES
-----

1. digit_count.cpp
   Counts the number of digits in a given number using recursion.
   Example: Input 12345 -> Output: Digits = 5

2. digits_sum.cpp
   Calculates the sum of digits of a given number using recursion.
   Example: Input 123 -> Output: Digit Sum = 6

3. evennumbers.cpp
   Intended to print even numbers within a given range.
   STATUS: This file is currently empty. Code needs to be added.

4. factorial.cpp
   Calculates the factorial of a given number using recursion.
   Example: Input 5 -> Output: Factorial = 120

5. fibonacci.cpp
   Prints the Fibonacci series up to a given number of terms using
   recursion.
   Example: Input 5 -> Output: 0 1 1 2 3

6. numbers_print_.cpp
   Prints all numbers from a starting point to an ending point using
   recursion.
   Example: Input 3 to 7 -> Output: 3 4 5 6 7

7. power.cpp
   Calculates the power of a number (base raised to an exponent) using
   recursion.
   Example: Input base 2, power 4 -> Output: Answer = 16

8. reverse.cpp
   Reverses the digits of a given number using recursion.
   Example: Input 123 -> Output: Reverse = 321

9. sum.cpp
   Calculates the sum of all numbers between two given numbers using
   recursion.
   Example: Input 1 to 5 -> Output: Sum = 15


HOW TO RUN
----------

1. Compile any file using a C++ compiler:
   g++ filename.cpp -o filename

2. Run the compiled program:
   ./filename


NOTE
----

These programs were written for practice purposes and are kept simple
and beginner-friendly. Most of them use recursion instead of loops to
solve the problem.
